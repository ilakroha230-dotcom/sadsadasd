# Hyvinkään Siivouspalvelu Oy — website

Premium single-page website for a Finnish cleaning company.

## Files
- `index.html` — markup, SEO meta, structured data
- `css/style.css` — custom styles (no frameworks)
- `js/script.js` — vanilla JS: i18n (FI/EN), reveal, counters, parallax, form
- `assets/favicon.svg`

## Run locally
Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Notes
- Contact form is front-end only; wire it to your backend/Formspree by setting the form `action`.
- Replace placeholder phone, email, address and Y-tunnus with real values.
- Replace Unsplash image URLs with real project photos for production.
